# hero-product

Custom **hero** block. Purpose: Top-of-page brand banner: full-width photo background, large uppercase headline, intro copy, CTA button and a product cutout image overlapping the bottom edge.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: background image; row 2: heading (h1), intro paragraph, CTA link, optional product image (picture). The product image may also be authored as its own picture-only cell.

## Supported variations

No variations.
