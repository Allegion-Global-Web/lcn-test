# cards-icon-links

Custom **cards** block. Purpose: Quick-links band: a row of small circular icons, each beside a short linked label.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: icon image; cell 2: link whose text is the label (e.g. 'Download Templates'). The icon becomes part of the same link.

## Supported variations

No variations.
