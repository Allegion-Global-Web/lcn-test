# hero-promo

Custom **hero** block. Purpose: Brand promo banner: background photo with a large overlapping colored text panel (logo, heading, paragraphs, CTA) and a circular badge image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: background image; row 2: optional logo picture, heading (h2), paragraphs, CTA link, optional badge picture after the heading. The badge may also be a separate picture-only row.

## Supported variations

No variations.
