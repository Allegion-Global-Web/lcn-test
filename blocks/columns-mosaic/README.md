# columns-mosaic

Custom **columns** block. Purpose: Image mosaic: a fixed grid mixing photo tiles, a video link tile (play icon + title) and solid-color text tiles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: rows of up to three cells; each cell is one tile: a picture only (photo tile), a play icon plus a YouTube/Vimeo link (video tile), or heading/paragraph text (text tile). E.g. row 1: video tile | wide photo; row 2: photo | photo | 'A Shared Commitment' text.

## Supported variations

No variations.
