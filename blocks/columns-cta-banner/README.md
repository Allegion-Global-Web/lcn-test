# columns-cta-banner

Custom **columns** block. Purpose: Contained call-to-action banner: heading, short copy and a button beside an icon box.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row, two columns. column 1: heading, paragraph(s), CTA link in its own paragraph; column 2: icon image (picture only). Column order may be swapped; the picture-only column is the icon.

## Supported variations

No variations.
