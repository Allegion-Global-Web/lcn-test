# accordion-product

Custom **accordion** block. Purpose: Product details accordion (features, specifications, finishes, mounting options, downloads), all items collapsed on load.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per item. cell 1: title (plain text); cell 2: content (paragraphs, bold sub-heads or headings, bulleted lists, PDF/video links). Any number of rows; a single-cell row continues the previous item's content.

## Supported variations

No variations.
