# carousel-featured

Custom **carousel** block. Purpose: Featured product/news carousel: one slide visible at a time, each a panel with eyebrow, title, description and outlined CTA beside an image or infographic.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: slide image (picture only); cell 2: optional eyebrow paragraph, title heading, description paragraph, CTA link. Cell order may be swapped; the picture-only cell is treated as the image.

## Supported variations

No variations.
