# columns-stat

Custom **columns** block. Purpose: Stat callout: a short statement paragraph beside a graphic that shows the statistic (e.g. '10x' tolerance image).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: cell 1 statement paragraph; cell 2 stat image, optionally wrapped in a link (e.g. to a PDF article).
