# cards-attributes

Custom **cards** block. Purpose: Product attribute list: small line icons, each beside a short label; some labels link to a related page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per attribute. cell 1: icon image; cell 2: label text, or a link whose text is the label. Any number of rows; empty cells are dropped.

## Supported variations

No variations.
