# cards-hub-tiles

Custom **cards** block. Purpose: Hub page entry points: full-width tiles linking to category detail pages (e.g. Solutions by Market / Role / Requirement).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per tile: cell 1 tile image; cell 2 heading linked to the detail page, description paragraph. The heading link (or the first link in the tile) becomes the whole-tile link.

## Supported variations

No variations.
