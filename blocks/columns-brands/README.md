# columns-brands

Custom **columns** block. Purpose: Related or partner brands: each column a brand logo linking to the brand site above a short description.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell per brand: brand logo image (optionally linked to the brand site), description paragraph(s). Empty spacer paragraphs are removed.

## Supported variations

No variations.
