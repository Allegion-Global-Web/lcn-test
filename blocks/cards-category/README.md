# cards-category

Custom **cards** block. Purpose: Solution category pages (by market, by role): a grid of linked category cards, one per detail page.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card (any count): cell 1 card image (optionally linked); cell 2 heading (H4) linked to the detail page, description paragraph. The heading link (or the first link in the card) becomes the whole-card link.

## Supported variations

No variations.
