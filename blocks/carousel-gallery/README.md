# carousel-gallery

Custom **carousel** block. Purpose: Product image gallery: one large product image at a time with round thumbnail navigation, auto-rotating.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per gallery image. cell 1: image (alt text kept); cell 2: optional caption text (usually empty). Any number of rows; rows without an image are ignored; a single image renders without controls.

## Supported variations

No variations.
